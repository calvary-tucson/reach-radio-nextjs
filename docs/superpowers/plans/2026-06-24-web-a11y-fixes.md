## Task 3 — Route change announcer

**Files:** New `src/components/bridge/RouteAnnouncer.tsx` + `src/app/layout.tsx`

When Next.js navigates (pathname changes), VoiceOver/TalkBack in a WebView gets no cue the page changed.

Create a client component that:
1. Watches `usePathname()`
2. On change, sets text in a visually-hidden `aria-live="polite"` region to the current `document.title`
3. After a short delay (100ms), moves focus to `document.getElementById('main-content')`

Rules:
- The `<main id="main-content">` already exists in `layout.tsx`
- Render `<RouteAnnouncer />` inside the root layout
- The live region must always be in the DOM (not conditionally rendered)
- Add `tabIndex={-1}` to the `<main>` so it can receive programmatic focus without visible ring — use `outline-none` or `focus:outline-none`

Commit: `fix(layout): announce route changes to screen readers`

## Task 5 — BottomSheet dialog semantics + focus trap + focus-return

**File:** `src/components/global/BottomSheet.tsx`

Currently `role="dialog"` / `aria-modal` / `aria-label` are on an outer wrapper div, but `ref={sheetRef}` and `tabIndex={-1}` are on the inner div. VoiceOver requires focus to land on the `role="dialog"` element to enter modal mode.

Fix all three issues together:

1. **Merge the wrapper**: Remove the outer `<div role="dialog" aria-modal="true" aria-label={ariaLabel}>` wrapper. Move `role="dialog"`, `aria-modal="true"`, `aria-label={ariaLabel}` directly onto the inner div that has `ref={sheetRef}` and `tabIndex={-1}`. The inner div becomes the single dialog root.

2. **Focus trap**: When the sheet is open, Tab and Shift+Tab must stay within the sheet. In the `keydown` useEffect (already listening for Escape), also handle Tab:
   ```ts
   if (e.key === 'Tab') {
     const focusable = sheetRef.current?.querySelectorAll<HTMLElement>(
       'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
     )
     if (!focusable?.length) { e.preventDefault(); return }
     const first = focusable[0]
     const last = focusable[focusable.length - 1]
     if (e.shiftKey && document.activeElement === first) {
       e.preventDefault(); last.focus()
     } else if (!e.shiftKey && document.activeElement === last) {
       e.preventDefault(); first.focus()
     }
   }
   ```

3. **Focus-return on close**: Before the open animation starts, capture `document.activeElement`. After the close animation ends (after `setTimeout(onClose, 280)`), call `.focus()` on the captured element.
   - Store it in `triggerRef = useRef<HTMLElement | null>(null)`
   - Set it in the `useEffect` that runs when `open` becomes true (before `sheetRef.current?.focus()`)
   - Call `triggerRef.current?.focus()` at the end of `handleClose` after `onClose`

Commit: `fix(modal): fix BottomSheet dialog semantics, focus trap, and focus-return`
